Connect the page (one time)

Until this is done the site shows Facebook’s own feed widget, which already updates by itself. Connecting lets posts appear in the site’s own style.

  1. Casey signs in at developers.facebook.com and creates an app (type: Business).
  2. In Graph API Explorer, pick the app, choose the Texas 6 page, and generate a Page access token with the pages_read_engagement permission.
  3. Exchange it for a long-lived token and send it to whoever manages the site, along with the page ID (100092064403815).
  4. They save it as the FB_PAGE_TOKEN secret in Supabase. Sync runs every hour after that.
